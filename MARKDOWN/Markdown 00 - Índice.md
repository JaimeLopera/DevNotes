# Markdown — Índice

> [!info] ¿Qué es esta carpeta?
> Aquí está todo lo que necesitas para escribir en Markdown: desde cero hasta las funciones extra de Obsidian y GitHub. Sirve para repasar rápido o para aprender el tema desde el principio.

## Orden recomendado

1. Lee **01** para entender la idea.
2. Sigue de **02 a 07**: es la sintaxis básica que sirve en cualquier sitio.
3. Pasa a **08 y 09** para las funciones extra según dónde escribas.
4. Termina con **10** y guarda **11** como chuleta.
