# SQL — Índice

> [!info] ¿Qué es esta carpeta?
> Aquí está todo lo necesario para trabajar con bases de datos relacionales usando SQL: desde consultar datos hasta diseñar una base de datos completa. Sirve para repasar rápido o para aprender desde cero.

## Orden recomendado

1. **Consultar:** 01 → 08. Es lo que más se usa en el día a día.
2. **Modificar datos:** 09 → 11.
3. **Diseñar la base de datos:** 12 → 16.
4. **Temas avanzados:** 17 → 19.
5. Guarda **20** como chuleta.

> [!tip] Base de datos de ejemplo
> Todos los ejemplos usan la misma base de datos de una tienda. Se define en [[SQL 01 - Fundamentos]].
