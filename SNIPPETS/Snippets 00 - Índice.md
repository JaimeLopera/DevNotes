# 00 - Índice

> [!info] Snippets
> Un **snippet** es un fragmento de código **listo para copiar y pegar** que resuelve una necesidad concreta y frecuente. Esta carpeta no explica: **recopila soluciones probadas**. Cada snippet enlaza a la nota donde se explica a fondo.

---

## 1. Cómo usar esta carpeta

- Busca por **necesidad** ("centrar un div", "validar un email"), no por tema.
- Copia, pega y **adapta** nombres y valores a tu proyecto.
- Si no entiendes por qué funciona un snippet, sigue su enlace antes de usarlo en algo importante.

> [!tip] Buscar rápido
> Usa la búsqueda de Obsidian (`Ctrl + Shift + F`) con palabras como "modal", "debounce" o "paginación".

## 4. Cómo añadir un snippet nuevo

Sigue siempre el mismo formato, para que todos se lean igual:

````markdown
### N.N Título que describe la necesidad

Para qué sirve, en una línea.

```lenguaje
código
```

Más en [[nota donde se explica]].
````
